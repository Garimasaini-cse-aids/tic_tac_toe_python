# 🎮 Tic-Tac-Toe Game | Python

A command-line Tic-Tac-Toe game developed using Python as part of the **Python Essentials 1 course by Cisco Networking Academy**.

## 📌 About the Project

This project is a simple implementation of the classic Tic-Tac-Toe game where a human player competes against the computer.

The game uses a 3×3 board, and the computer selects its moves randomly from the available positions.

## ✨ Features

- Interactive 3×3 game board.
- Human vs Computer gameplay.
- Random computer moves.
- Input validation to prevent invalid moves.
- Automatic win detection across rows, columns and diagonals.
- Tie detection when the board is full.

## 🛠️ Concepts Used

- Python functions
- Lists and nested lists
- Loops and conditional statements
- Tuples
- User input and validation
- Random number generation using `randrange()`

## ▶️ How to Run

1. Install Python 3.
2. Clone this repository:
   git clone https://github.com/Garimasaini-cse-aids/tic_tac_toe_python.git

3. Navigate to the project folder.
4. Run the game:
   python tic_tac_toe.py
